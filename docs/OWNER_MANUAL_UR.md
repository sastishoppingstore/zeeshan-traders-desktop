# مالک کا دستورالعمل — ذیشان ٹریڈرز (اردو)

> یہ دستورالعمل اصل، چلنے والے سسٹم کے لیے ہے۔ جو چیزیں ابھی مکمل نہیں، وہ واضح طور پر **INCOMPLETE** لکھی گئی ہیں۔
> تاریخ: ۳ نومبر ۲۰۲۶ ء۔

## ۱۔ سسٹم کیا ہے؟

ایک ہی ڈیٹابیس (Cloudflare D1) اور ایک ہی مصنوعات کی فہرست پر دو حصّے:

1. **عوامی ویب سائٹ** (`/`) — صرف نام، پتہ، دو فون نمبر، واٹس ایپ، اور وہ مصنوعات جو آپ خود شائع کریں۔
   لاگت، مارجن، سپلائر، اصل اسٹاک، گاہکوں کے نام یا اندرونی نوٹ کبھی عوام کو نہیں بھیجے جاتے۔
2. **نجی کھاتہ / ERP** (`/erp`) — ۱۷ الگ کتابیں، آف لائن کام، رسیدیں، رپورٹیں، پرنٹ، بیک اپ۔

**کوئی فرضی ڈیٹا نہیں:** قیمتیں، اسٹاک، بیلنس، لائسنس نمبر، ای میل، اوقات، تبصرے، گاہک اور سپلائر سب خالی ہیں جب تک آپ خود درج نہ کریں۔

## ۲۔ پہلی بار چلانا (مقامی پیش نظارہ)

```bash
npm install --no-audit --no-fund
npm run migrate:local
npm run build:web
npm run server
```

سرور پہلی بار **ایک بار استعمال ہونے والا «سیٹ اپ ٹوکن»** ٹرمینل پر پرنٹ کرتا ہے اور `.dev/secrets.json` میں محفوظ کرتا ہے (صرف اسی کمپیوٹر پر، Git میں نہیں جاتا)۔
براؤزر میں `/erp` کھولیں۔

> **پیداوار (Cloudflare) میں** `EXPOSE_SETUP_TOKEN` کبھی آن نہ کریں؛ ٹوکن `wrangler secret put SETUP_TOKEN` سے دیا جاتا ہے اور تعیناتی کرنے والے کو ایک بار دکھایا جاتا ہے۔
> **ابھی Cloudflare تعیناتی INCOMPLETE ہے** — نیا پروجیکٹ `wrangler.v2.jsonc` تیار ہے اور staging/production خشک رن (dry-run) دونوں exit 0 ہیں، مگر اس sandbox سے Cloudflare API ناقابلِ رسائی ہے (`SSL_ERROR_SYSCALL`)، اس لیے کوئی حقیقی عوامی URL نہیں ہے۔ ڈومین بھی آپ نے بعد کے لیے رکھا ہے۔

## ۳۔ سیٹ اپ وزرڈ (۷ قدم)

| قدم | کیا درج کریں | یاد رکھیں |
|---|---|---|
| ۱ | مالک کا نام، صارف نام، موبائل، پاس ورڈ | پاس ورڈ کم از کم ۱۰ حروف؛ کوئی «ڈیفالٹ پاس ورڈ» نہیں |
| ۲ | کاروباری پروفائل | نام/پتہ/فون پہلے سے درج ہیں؛ لوگو بعد میں ترتیبات میں |
| ۳ | **ایک من = کتنے کلو؟** | *آپ کی تصدیق لازمی*؛ اس کے بغیر «فی من» ریٹ بلاک رہتا ہے |
| ۴ | ابتدائی بیلنس (اختیاری) | نقد، جاز کیش، میزان، UBL — جو کچھ نہ ہو خالی چھوڑ دیں |
| ۵ | مالی سال | پہلے سے جولائی–جون، ہفتہ سے آغاز |
| ۶ | ریگولیٹری (اختیاری) | اصل لائسنس نمبر/تاریخ صرف آپ درج کریں — سسٹم کبھی نہیں بناتا |
| ۷ | خلاصہ | کیٹلاگ خالی، کوئی گاہک/سپلائر نہیں |

سیٹ اپ دوبارہ نہیں چل سکتا۔

**مالک سے درکار معلومات (NEEDS OWNER INPUT):** من کا کلو، بیگ سائز / یونٹ کنورژن، لائسنس نمبر و میعاد، ابتدائی بیلنس، ڈومین نام، Cloudflare رسائی، اور ضلع زراعت دفتر لیہ سے موجودہ ضوابط کی تصدیق۔
یہ سافٹ ویئر کسی سرکاری پورٹل، بینک یا JazzCash میں فائلنگ/انٹیگریشن نہیں کرتا — صرف ریکارڈ اور ایکسپورٹ رکھتا ہے۔

### وزن کا حساب (اجناس)
```
کچا وزن − (بوریاں × فی بوری وزن) − کٹوتیاں = خالص وزن (گرام میں، مکمل عدد)
```
ہر لائن اسکرین پر لکھی جاتی ہے اور دستاویز کے JSON سنیپ شاٹ میں محفوظ ہوتی ہے۔ «من» کی تبدیلی صرف آپ کی تصدیق کے بعد۔

### پیسہ اور تعداد
* رقم ہمیشہ **پیسہ** (integer) میں محفوظ ہوتی ہے — `Rs 1,250.50` = `125050`۔ کوئی اعشاری فلوٹ نہیں۔
* تعداد ہمیشہ **ملی یونٹ** میں — بنیادی یونٹ `kg` ہو تو ۱ ملی = ۱ گرام۔
* کوئی پوسٹڈ مالی ریکارڈ ایڈٹ/ڈیلیٹ نہیں ہوتا: «واپسی» = ریورس + نیا ریکارڈ، وجہ، صارف اور وقت کے ساتھ۔

## ۵۔ پرنٹ اور PDF

تمام دستاویزات براؤزر میں HTML+CSS سے بنتی ہیں تاکہ اردو کے جوڑ درست رہیں (سرور پر PDF لائبریری استعمال نہیں)۔
`/erp/documents` سے دستاویز کھولیں → `🖨 پرنٹ / PDF` → براؤزر کا **Save as PDF**۔
سائز: A4، A5، 80mm تھرمل۔ ہر دستاویز کے ساتھ JSON سنیپ شاٹ اور `template_version` محفوظ ہے، یعنی بعد میں قیمت بدلنے پر پرانا بل نہیں بدلتا۔

## ۶۔ آف لائن کام

* انٹرنیٹ بند ہونے پر اندراج **PROVISIONAL** نمبر کے ساتھ مقامی (IndexedDB) قطار میں جاتا ہے۔
* سنک چار طریقوں سے چلتا ہے: ایپ کھلنے پر، `online` ہوتے ہی، اسکرین نظر آتے ہوئے ہر ۶۰ سیکنڈ، اور «ابھی سنک کریں» بٹن۔
* ہر آپریشن کا منفرد `idempotency_key` ہے — دوبارہ بھیجنے پر ڈبل پوسٹنگ نہیں ہوتی۔
* دو آلات ایک ہی آخری اسٹاک بیچیں تو خاموش اوور رائٹ نہیں، **CONFLICT** فلیگ بنتا ہے؛ `/erp/sync` میں «وجہ» کے ساتھ ACCEPT یا REJECT کریں۔
* لاگ آؤٹ یا ڈیوائس ریووک پر رول کے مطابق کیش صاف ہو جاتا ہے۔
* **PIN کیش انکرپشن:** `/erp/settings` میں ۴–۱۲ ہندسوں کا PIN دیں۔ PBKDF2 (۳۱۰٬۰۰۰ چکر) → AES-256-GCM؛ کیش ہمیشہ انکرپٹڈ، چابی صرف میموری میں، لاک/لاگ آؤٹ/ری لوڈ پر ختم۔ PIN کہیں بھیجا یا محفوظ نہیں ہوتا۔ PIN بھول گئے تو صرف مقفل کیش صاف کیا جا سکتا ہے، سنک کی قطار محفوظ رہتی ہے۔ ۴ یونٹ ٹیسٹ + حقیقی Chromium براؤزر E2E پاس (IndexedDB میں ۴/۴ قطاریں انکرپٹڈ)۔

> **فنگر پرنٹ لاگ ان (WebAuthn پاس کی) اب COMPLETE ہے** — لاگ ان اسکرین اور `/erp/users` سے پاس کی رجسٹر کریں، لاگ ان کریں اور ریووک کریں۔ حقیقی Chromium virtual authenticator E2E پاس (`A15_E2E_PASS`)؛ ریووک کے بعد لاگ ان `401 PASSKEY_NOT_FOUND` دیتا ہے اور پاس ورڈ فال بیک کام کرتا ہے۔ فنگر پرنٹ ڈیوائس میں رہتا ہے، ویب سائٹ بائیو میٹرک کبھی نہیں دیکھتی — سرور صرف عوامی کلید رکھتا ہے۔ **پیداوار میں حتمی ڈومین (RP_ID/RP_ORIGIN) سیٹ ہونے کے بعد ہی پاس کی رجسٹر کریں**، کیونکہ پاس کی ڈومین سے بندھی ہوتی ہے۔

## ۷۔ بیک اپ اور بحالی

رات کو کران خودکار بیک اپ لیتا ہے: NDJSON → gzip → AES-GCM → `backups/` (پرائیویٹ R2)۔
`/erp/backup` سے فوری بیک اپ اور ڈاؤن لوڈ بھی ممکن ہے۔
**بیک اپ تبھی درست مانا جاتا ہے جب staging پر بحالی ٹیسٹ پاس ہو** — پہلے staging، کبھی بھی سیدھا production نہیں:

```bash
npx tsx scripts/restore.ts --file backup.ztbak --key "$BACKUP_ENCRYPTION_KEY" --verify-only
npx tsx scripts/restore.ts --file backup.ztbak --key "$BACKUP_ENCRYPTION_KEY" \
  --target .dev/restore-test.db --i-know-this-is-staging
```

مقامی staging-ہمسر ٹیسٹ میں ۱٬۰۳۲ قطاریں بحال ہوئیں، `foreign_key_check: PASS` اور جرنل متوازن (ڈیبٹ = کریڈٹ = ۹۷٬۹۳۹٬۲۶۷ پیسہ)۔
**حقیقی Cloudflare staging بحالی ابھی INCOMPLETE ہے**، اس لیے `staging_restore_result = NOT_TESTED` ہے۔ D1 Time Travel (۷ دن Free / ۳۰ دن Paid) صرف حفاظتی جال ہے، بیک اپ کا متبادل نہیں۔

## ۸۔ حدیں اور انتباہ

* `/erp` ڈیش بورڈ D1 استعمال دکھاتا ہے۔ مفت پلان: ۵۰ لاکھ پڑھائی / ۱ لاکھ لکھائی یومیہ؛ ۷۰٪ پر انتباہ۔ **پیداوار کے لیے Workers Paid تجویز ہے** (مفت میں CPU صرف ۱۰ ملی سیکنڈ)۔ حد ختم ہونے پر D1 کوئریز ایرر دیتی ہیں، ۰۰:۰۰ UTC تک۔
* کسی بھی قانونی ضابطے (پیسٹی سائیڈ / کھاد لائسنس، ریکارڈ کی مدت، نومبر ۲۰۲۶ کی eBiz تاریخ) کی **تصدیق آپ خود ضلع زراعت دفتر لیہ سے کریں**؛ سافٹ ویئر اسے حتمی قانونی مشورہ نہیں دیتا۔
* رازداری / شرائط کے صفحات `REVIEW_REQUIRED` ہیں جب تک آپ قانونی جائزہ مکمل نہ کریں — کوئی فرضی قانونی متن نہیں لکھا گیا۔

| بند پیریڈ میں پوسٹنگ | `PERIOD_CLOSED` آئے گا؛ کھلے پیریڈ میں وجہ کے ساتھ ریورس + نیا ریکارڈ |

## ۱۰۔ ابھی کیا مکمل نہیں

Cloudflare تعیناتی اور حقیقی URLs، حقیقی Cloudflare Turnstile / ایج کیش کی تصدیق، حقیقی staging بحالی،
پیداوار R2 بائنڈنگ، حقیقی فون/Android ڈیوائس پر اسکرین شاٹ، رات کا خودکار R2 بیک اپ، عالمی سرچ انڈیکس،
MANUAL الاٹمنٹ / ریٹرن لائن چننے والے UI، اور قانونی متن کی مالک کی منظوری۔
**جو مکمل ہو گیا:** پاس کی، PIN E2E، ۴۴ بصری baselines (۰٪ فرق)، Lighthouse ۱۰۰/۱۰۰/۱۰۰،
axe صفر violations، اردو PDF ثبوت (ڈیسک ٹاپ + Android emulation)، CSRF/SQLi/XSS/IDOR گیٹس، اور نئے پروجیکٹ کی خشک تعیناتی۔
مکمل فہرست: `docs/KNOWN_LIMITATIONS.md` اور لائیو `/erp/status` (`GET /api/v1/features`)۔
**جو کام نہیں ہوا اسے کبھی «مکمل» نہیں کہا گیا۔**
